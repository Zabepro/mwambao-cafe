# Mwambao Café

A modern, responsive website celebrating the coastal atmosphere, authentic Swahili dishes, and coffee culture of Dar es Salaam.

## Tech Stack
- HTML5 (Semantic Structure)
- CSS3 (Vanilla Styling)
- JavaScript (Vanilla ES6+)
- GitHub (Version Control & Repository Hosting)
- Netlify (Static Site Deployment)

## How to Run Locally
You can run this project locally without any installation or build steps:

1. **Direct Browser Execution**:
   - Locate and double-click `index.html` or drag-and-drop it into any modern web browser (Chrome, Edge, Firefox, Safari).

2. **Using VS Code Live Server**:
   - Open this repository folder in VS Code.
   - Right-click on `index.html` and select **"Open with Live Server"** (or click "Go Live" in the bottom status bar).
   - The site will open automatically at `http://127.0.0.1:5500/`.
